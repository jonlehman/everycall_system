## Coverage and exclusions

The migration is the authoritative explicit column allowlist. Tables: sales_prospects (company/contact legacy fields, permissions, suppression, owner, callback, status, import/source references, named research metadata); sales_prospect_contacts (name, email, title, decision/influencer, memo, archival); sales_prospect_contact_numbers (person/shared association, number, type, label, order, archival); sales_prospect_notes (append-note body and call link); sales_call_sessions (live/wrap-up notes, outcome/dispositions, callbacks, business state, company association and times); sales_dnc_registry (identity/reason); sales_dialer_config (individual shared scripts, phone-test/pricing settings); sales_operator_settings (display name, caller ID, active); sales_setup_bookings (schedule/attendee/status); sales_checkout_sessions (chosen channel/recipient/amount/status, excluding URLs/tokens/payment credentials); sales_incoming_calls (business association/state/message).

Database capture also covers imports, backfills, trigger-derived legacy synchronization, workers and provider business-state updates. Authenticated request-scoped pool adapters set actor context from the server session, never body/header fields. Internal jobs/gateway/old binaries default to System / unattributed. A provider response synchronously persisted inside an authenticated request retains the initiating human's request context; subsequent provider callbacks are System. Auto-assignment performed by a queue GET is explicitly System. Migration enables capture before new actor-aware code; this transition is disclosed as System / unattributed.

Exclude passwords, auth sessions, telephony credentials, tokens, raw provider events/payloads/transcripts/recording URLs, machine demo/build artifacts, private phone-test originals, snapshots/identity history, general metadata, row versions, created/updated bookkeeping timestamps and queue-position churn. Do not copy the restricted ledger into the existing general audit log. Admin-user account profile changes remain in existing account audit; only Sales operator settings belong here. No CSV export in this release; complete individual field values are available in the guarded detail endpoint.
