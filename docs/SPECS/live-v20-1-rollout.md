# Managed Live v20.1 rollout

v20.1 is opt-in per tenant. Existing tenants without a `tenant_live_prompt_settings` row remain on the legacy managed prompt. New tenants are created with `live_prompt_mode=pending_v20` and cannot enter live calls until the two callback-role values are explicitly confirmed and an active curated brief exists. A material role edit removes confirmation. Unconfirmed trade defaults never enter a Live payload.

1. Apply only additive migrations 0049 and 0050 using `EVERYCALL_APPLY_LIVE_V201_MIGRATIONS=1 pnpm migrate:live-v20-1` before deploying code. Confirm both entries in `schema_migrations`. Do not let a new gateway binary query the new columns before this step.
2. Run `node scripts/validate-managed-live-runtime.mjs`, `node scripts/validate-live-brief-curation.mjs`, `node scripts/validate-live-prompt-settings.mjs`, `node scripts/validate-client-setup-status.mjs`, `pnpm --filter @everycall/call-gateway build`, and the web build. Keep `apps/worker/src/worker.js` and `artifacts/` changes outside this release unless separately reviewed.
3. Prepare the active knowledge build offline. Newly published/rolled-back builds curate fixed slots before the active pointer changes. Older active builds require an explicit build/republication; no generation runs during prompt fetch. Review empty slots and source provenance. The application omits stale facts without a real crawl timestamp rather than inventing one.
4. In tenant Basics, the owner/admin reviews and explicitly confirms the callback role and what that person will do. The saved role and active brief must both be ready before `live_prompt_mode=v20_1`. The global feature flag remains off, so confirmation alone does not switch production speech.
5. Use a non-production environment or an approved isolated test tenant. Set `EVERYCALL_LIVE_V201_CANARY_TENANTS=<exact tenant_key>` on both the Vercel API and Render gateway; leave `EVERYCALL_LIVE_V201_ENABLED=0`. Make one scheduled audible Telnyx test call. In transcript and redacted audit, verify the callback offer ID precedes the caller's explicit yes, an ambiguous/competing answer did not grant consent, the exact phone read-back was confirmed, contact capture completed once, and no delegation filler interrupted the flow. Also verify caller-heard audio; a Telnyx write is not that proof.
6. Only after independent review and canary acceptance, enable `EVERYCALL_LIVE_V201_ENABLED=1` on both services for confirmed tenants. Keep pending tenants blocked. Roll back v20.1 by setting this flag to `0` and clearing `EVERYCALL_LIVE_V201_CANARY_TENANTS` on both services; confirmed tenants then receive the legacy managed payload. Switching `CALL_GATEWAY_VOICE_RUNTIME=realtime` remains a separate rollback and retains the canonical prompt.

The software is not considered live-accepted from offline tests, builds, or an API status alone. A failed or unavailable audible canary stops global activation.
