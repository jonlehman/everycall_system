# Collaboration Guide

## Where to Find Specs
- PRD: `docs/PRD.md`
- Feature specs: `docs/SPECS/*.md`
- Decisions: `docs/DECISIONS.md`
- Tests: `docs/TESTS.md`
- Runbook: `docs/RUNBOOK.md`

## Expectations for Changes
- If behavior changes, update relevant spec.
- If a design choice is made, add it to `docs/DECISIONS.md`.
- Add/adjust call test scripts when prompts or routing change.

## Review Checklist
- Does the change affect prompts or FAQs?
- Does it change call flow or pre-close behavior?
- Does it impact barge-in or audio timing?
